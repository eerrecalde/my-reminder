# Android icon preview

Previewed 11 November 2026 on the disposable `pill_reminder_test` Android 16 emulator, using the bundled release app with Wi-Fi and mobile data disabled. Screenshots use test-only Reminder and Medicine occurrences. British English and Latin American Spanish were checked.

Keep the shared artwork at **24 dp with a 2 dp stroke** for this rollout. The clock is legible in the occurrence badge and History tab, and the open and closed chevrons fit the Repeat control and Today outcome groups. The long Spanish missed-outcome label also fits alongside the chevron. No previewed inline control required a 20 dp option. Badge and tap-area dimensions remain independent of artwork size.

The `files/` screenshots show Today groups closed, expanded Reminder and Medicine groups, History, and Repeat closed and open in each language. The longer Reminder name intentionally wraps to check spacing. Captures are visual checks, not evidence of physical-device behaviour.
