# 03: Standardise icons in Reminder and Medicine setup

**What to build:** Make it easy to tell which setup controls open a picker or another screen, see which schedule options are selected, and recognise Back and add-time actions.

**Blocked by:** 01 — Preview the clock and chevrons on Android.

**Status:** ready-for-agent

- [ ] Use the shared right-facing chevron for schedule setup rows that open a picker or another screen. Retain the Frequency dropdown’s down and up chevrons for expanding in place.
- [ ] Use the shared icon treatment for Back, add-time, and the checked and unchecked states of schedule selection controls. Preserve the existing names, roles, selection states and tap areas. Keep decorative artwork out of accessibility announcements where the parent conveys the same information.
- [ ] Run the existing setup and scheduling tests. On the disposable Android emulator, exercise Reminder and Medicine setup in British English and Latin American Spanish. Check that picker rows open, selections remain readable, a time can be added and Back works with the updated icons.
