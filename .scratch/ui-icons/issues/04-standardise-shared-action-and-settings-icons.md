# 04: Standardise shared actions and settings icons

**What to build:** Give shared actions, menus, settings and reminder access the same icon style as the rest of the app, so people can recognise the controls wherever they use them.

**Blocked by:** 01 — Preview the clock and chevrons on Android.

**Status:** ready-for-agent

- [ ] Apply the shared icon treatment to app menus, shared add buttons, warning and access indicators, and rows in settings and sound controls that open a picker or another screen. Use the shared right-facing chevron for those rows.
- [ ] Preserve visible labels, accessible names and states, and existing tap areas. Keep warning and access messages available as text.
- [ ] Run the standard React Native checks. On the disposable Android emulator, exercise the updated menus, add action, settings and reminder access in British English and Latin American Spanish. Check the shared sound control in both settings and setup, and confirm the updated icons render offline.
