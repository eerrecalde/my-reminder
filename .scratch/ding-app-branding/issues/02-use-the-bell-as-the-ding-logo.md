# 02: Use the bell as the Ding logo

**What to build:** People can recognise the app by the same simple bell in the Android launcher, the shared app header and the native Alarm screen.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Use the same bell mark across the existing launcher icon variants, the shared app header and the native Alarm screen in both languages.
- [ ] On a disposable Android emulator, capture the launcher and both in-app surfaces. Confirm the bell is recognisable at launcher size, including under round and adaptive icon masks.
- [ ] Check the bell and name together on a compact screen in English and Spanish. Confirm the name is legible and the existing header actions have room.
- [ ] Keep the artwork change to branding surfaces. Preserve functional icons, system notification icons, alert sounds and the Alarm screen's existing privacy and behavior.

See the [Ding app name and bell logo spec](../spec.md).
